- 서비스명: spaceLog (화면정의서의 "우주 아카이브")
- 버전: v0.6 (2026-11-11)
- 기준 문서: 우주 아카이브 화면정의서 v0.1
- 시안: https://claude.ai/artifact/S4EszBcGwiGS7Ny3xdGnhb (파일: [spacelog-prototype.html](spacelog-prototype.html))
- 범위: 로컬 웹 W-00 ~ W-04. 수집 앱(S-01 ~ S-04)은 다루지 않는다.
- 수집 앱 디자인: 디자이너 2의 "SPACELOG design.md"를 기준으로 한다. 그 문서의 규칙 중 이 문서의 방향과 맞는 것은 v0.3에서 합쳤다(17장).
- 디자인 담당: W-00 ~ W-04 전체

이 문서는 개발자가 이것만 보고 화면을 만들 수 있게 쓴 인수인계서다. AI에게 넘겨 같은 스타일로 화면을 만들게 할 때도 쓴다. 규칙은 "~한다 / ~하지 않는다"로 단정해서 쓴다. **문서와 시안이 다르면 문서가 기준이다.** 다른 점은 15장에 모아 둔다.

## 1. 컨셉과 원칙

> 내가 막연히 기록하는 것들이 하나의 별, 행성, 우주가 된다.

| 현실 | 우주에서 | 비고 |
|---|---|---|
| 기록 1개 | 별 | 행성 주위를 돈다 |
| 카테고리 | 행성 | 기간 안의 별이 많을수록 커진다 |
| 기간 안의 기록 전체 | 우주 | 기본 기간은 오늘 |
| 고른 기록 묶음 | 탐사선 | 복사해서 Claude에 붙여넣는다 |

1. **조작 없이 다 보인다.** 우주에 들어오면 조망 상태에서 모든 행성이 한 화면에 보인다.
2. **클릭 2번 안에 행성에 닿는다.** W-00 또는 W-01의 행성 목록에서 바로 날아간다.
3. **비행은 선택이다.** 목록과 버튼만으로 모든 일을 할 수 있어야 한다.
4. **기록은 내 PC에만 있다.** 밖으로 나가는 것은 사용자가 탐사선에서 복사한 내용뿐이고, 화면에서 이 사실을 숨기지 않는다.

## 2. 비주얼 방향

장난감 같은 툰 3D. 두꺼운 잉크 외곽선, 3단계로 끊긴 음영, 각진 로우폴리 면, 2등신 캐릭터.

| 한다 | 하지 않는다 |
|---|---|
| 모든 3D 물체에 잉크색 외곽선 | 사실적인 질감, 반사, 블룸 남발 |
| 음영은 3단계로 끊는다 | 부드러운 그라데이션 음영 |
| 행성 면은 각지게(Icosahedron, flat shading) | 매끈한 구 |
| 2D UI는 3px 잉크 테두리 + 아래로 떨어지는 단색 그림자 | 흐린 그림자, 유리 효과(blur) |
| 원색에 가까운 밝은 색, 면적은 작게 | 화면 전체를 채도 높은 색으로 칠하기 |
| 배경은 짙은 남보라 우주 | 순수한 검정 배경 |
| 오래 보는 움직임은 느리게 | 계속 빠르게 도는 장식(어지럽다는 피드백 있었음) |

### 3-1. 컬러 (팀 원안, 기록용)

```css
:root {
  --ink:     #1a1430; /* 외곽선, 본문 글자, 그림자, 배지 바탕 */
  --space:   #15103a; /* 우주 배경, 웹 전체 바탕 */
  --panel:   #f4f2ff; /* 카드·패널 바탕 */
  --panel-2: #e6e2ff; /* 패널 안 2차 면, 푸터, 고스트 버튼, 탐사선 실은 목록 */
  --mute:    #5b5480; /* 보조 글자, 날짜, 안내 */
  --white:   #ffffff; /* 목록 항목, 입력창, 미리보기 바탕 */

  --yellow:  #ffd23f; /* 기본 버튼, 선택된 항목, 별 */
  --pink:    #ff5d8f; /* 고른 별, 새 항목 강조, 지우기 확정 */
  --violet:  #7a6cff; /* 탐사선, 우주로 들어가기, 체크박스 */
  --sky:     #5ec8ff; /* 키보드 포커스 링 */

  --notice:  #fff4c2; /* 탐사선 개인정보 안내 띠 */
  --danger-text: #c2185b; /* "이 별 지우기" 글자 링크 */

```

행성 색은 카테고리가 생기는 순서대로 돌려 쓴다. 9번째부터 처음으로 돌아간다.

| 순서 | 면 색 | 진한 색 | 시안 예시 |
|---|---|---|---|
| 1 | `#ff7a59` | `#b23a1c` | 제품 기획 |
| 2 | `#5ec8ff` | `#0f6aa8` | 21일차 수업 |
| 3 | `#8fdc5a` | `#2f7a1e` | 읽은 것들 |
| 4 | `#c29bff` | `#6a3fc8` | 생각 조각 |
| 5 | `#ffb13b` | `#8f5a00` | 새 행성 |
| 6 | `#ff6fb5` | `#b0246f` | |
| 7 | `#4fd1c5` | `#0d7068` | |
| 8 | `#9aa7ff` | `#3f4fc0` | |

- 글자는 `--ink` 또는 `--white`만 쓴다. 노랑 바탕에는 `--ink`, 보라·핑크 바탕에는 `--white`.
- 화면 하나에 포인트 색 버튼은 2가지까지만.
- 다크 테마 하나만 쓴다. 카드 안쪽만 밝다. 밝은 카드 안의 체크박스 · 선택 상자가 어둡게 나오지 않도록 카드에 `color-scheme: light`를 준다.
- **면 색**은 3D 행성, 색 점, 행성 아이콘에 쓴다. **진한 색**은 밝은 패널 위의 글자 · 선과, 흰 글자를 올리는 면에 쓴다. 진한 색 8개는 흰색과 `--panel` 양쪽에 대비 4.8 이상이다.
- **패널 포인트 색**: W-02 · W-03 패널 루트에 `--accent: (그 행성의 진한 색)`을 준다. 라벨, 체크박스, 체크된 행(진한 색 16% 면 + 진한 색 테두리), 패널 안 포커스 링, 행성 아이콘 바깥 링이 이 색을 쓴다. "탐사선에 싣기" 버튼은 탐사선의 색인 보라로 둔다. 패널 밖의 포커스 링은 `--sky` 그대로다.

### 3-2. 타이포그래피 (팀 원안, 기록용)

```css
:root {
  --f-display: "Black Han Sans", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;
  --f-body:    "Pretendard Variable", Pretendard, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;
  --f-mono:    "IBM Plex Mono", ui-monospace, Consolas, monospace;

```

| 역할 | 서체 | 크기 / 굵기 | 쓰는 곳 |
|---|---|---|---|
| 로고 | display | 26px (W-00 24px) | 로고 |
| 큰 제목 | display | clamp(26px, 4vw, 38px) | W-00 인사말 |
| 화면 제목 | display | 24px | 행성 이름 |
| 별 제목 | display | 19px, 줄간격 1.25 | W-03 머리 |
| 모달 제목 | display | 20px | 탐사선 |
| 버튼 | display | 15px (작은 버튼 13px, 큰 버튼 18px) | 모든 버튼 |
| 라벨 | display | 12px, 자간 0.06em, `--violet` | "이 행성을 도는 별들", "메모" |
| 본문 | body | 14px / 600, 줄간격 1.6 | 목록, 상세 |
| 보조 | body | 12.5px / 400, `--mute` | 부제, 안내 |
| 날짜 · 숫자 | mono | 11.5px, tabular-nums | 목록 날짜 |
| 미리보기 | mono | 13px, 줄간격 1.6 | 탐사선 |

- 제목은 Black Han Sans, 본문은 Pretendard, 날짜 · 숫자 · 미리보기는 IBM Plex Mono. 본문 굵기는 400과 600을 기본으로 쓴다.
- 한글은 단어 단위로 줄을 바꾼다(`word-break: keep-all`). 버튼 · 탭 · 키 표시는 줄바꿈하지 않는다(`white-space: nowrap`).
- 로컬 웹은 인터넷 없이도 열려야 한다. **서체 파일(woff2)은 로컬 서버에 같이 넣어서** 불러오고 CDN에 의존하지 않는다.

### 3-3. 모양과 간격 (팀 원안, 기록용)

```css
:root {
  --line: 3px;   --line-thin: 2.5px;
  --r-card: 16px; --r-btn: 12px; --r-item: 12px; --r-thumb: 8px; --r-pill: 999px;
  --drop-card: 0 5px 0 var(--ink);
  --drop-btn:  0 4px 0 var(--ink);
  --gap-1: 6px; --gap-2: 8px; --gap-3: 12px; --gap-4: 16px; --gap-5: 24px;
  --edge: 14px;  /* 화면 가장자리에서 떨어지는 거리 */
}
```

- 그림자는 흐리지 않는다. 항상 아래로 떨어지는 단색 잉크 그림자.
- 형제 요소 사이 간격은 `gap`으로 준다.
- 화면 위 2D 요소의 쌓임 순서: 3D(1) < 우주 위 UI(2) < 빈 상태·오류 카드(3) < W-00(20) < 전환 막(30) < 탐사선(40) < 확인 창(45) < 토스트(50).

### 버튼

| 종류 | 바탕 / 글자 | 쓰는 곳 |
|---|---|---|
| 기본 | `--yellow` / `--ink` | 복사하기, 날아가기, 새로고침, 만들기 |
| 보라 | `--violet` / `--white` | 우주로 들어가기, 탐사선, 싣기 |
| 핑크 | `--pink` / `--white` | 지우기, 합치기 확정 |
| 고스트 | `--panel-2` / `--ink` | 취소, 닫기, 홈, 원본 열기 |
| 글자 링크 | 투명 / `--danger-text`, 밑줄 | "이 별 지우기"(누르면 확인 창) |

- 올림: `translateY(-1px)` / 누름: `translateY(3px)`, 그림자 `0 1px 0` / 포커스: 3px `--sky` 외곽선, 2px 띄움 / 비활성: `--panel-2` 바탕, `--mute` 글자, 그림자 없음.

### 확인 창 규칙

삭제 · 합치기 · 새 행성 만들기에 쓴다. **브라우저 확인창(confirm, prompt)은 쓰지 않는다.**
- 제목: 무엇이 어떻게 되는지. 예: "별 'MCP가 뭐더라'을(를) 지울까요?"
- 설명: 되돌릴 수 없는 것과 남는 것. 예: "기록과 보관함 복사본이 함께 지워져요. 원본 파일은 그대로예요."
- 버튼: 고스트 "취소" + 핑크 확정(만들기는 노랑). Esc · 바깥 클릭 = 취소. 입력창에서 Enter = 확정.

### 아이콘

- **Lucide** 선 아이콘만 쓴다. 선 굵기 2.5px, 둥근 끝, 색은 글자색을 따른다(`stroke="currentColor"`). 인라인 SVG로 넣거나 로컬 서버에 파일로 둔다.
- 크기: 버튼 안 18px, 썸네일 17px, 이름 바꾸기 · 탐사선 16px, 칩의 빼기 12px.

| 쓰는 곳 | 아이콘 |
|---|---|
| 닫기, 칩에서 빼기 | x |
| 행성 메뉴 | ellipsis |
| 이름 바꾸기 | pencil |
| 목록으로 | arrow-left |
| 탐사선 | rocket |
| 썸네일: 텍스트 / 링크 / 파일 | type / link / file-text |

이모지와 직접 그린 그림은 쓰지 않는다. 로고는 글자로만 쓴다.

### 누르는 영역

누를 수 있는 요소의 누르는 영역은 최소 44px이다. 보이는 크기가 작은 것(34px 아이콘 버튼, 체크박스, 칩의 빼기)은 보이는 크기를 그대로 두고 투명한 영역만 넓힌다.

별 상한 초과 상태 (기간 안의 별 2,000개 초과, 수치는 잠정 · POLICY 성능 상한)

- **별은 하나도 그리지 않는다.** 행성은 평소대로 그리고 크기는 기본 반지름의 최대값(6)으로 둔다. 별 개수에 따른 커짐은 쓰지 않는다. 조망에서 모든 행성이 한 화면에 보이는 것은 그대로다.
- **행성마다 개수가 읽힌다.** 이름표 둘째 줄은 평소처럼 "별 1,240개"를 보여 준다(8장). 흰 글자 + 잉크 외곽선이라 어느 행성 색 위에서도 읽힌다. 왼쪽 아래 바로 날아가기 목록의 이름 · 개수는 그대로다.
- **띠 배너가 위 가운데, 기간 탭 바로 아래에 붙는다.** 문구는 "기간을 좁히면 별이 보여요", 그 오른쪽에 작은 기본 버튼 "오늘만 보기". 버튼을 누르면 기간이 오늘로 바뀐다. 기간이 이미 오늘이면 버튼은 넣지 않는다. 배너는 이 상태가 이어지는 동안 계속 보이고, 2,000개 이하가 되면 사라지며 별이 다시 나타난다. 760px 이하에서는 기간 탭 바로 위에 붙는다.
- 별 클릭은 없다. 행성 클릭 · E · 목록 · 재발견 카드는 그대로 동작하고, W-02 패널의 별 목록도 그대로 나온다. 체크한 별은 목록에서만 표시된다.
- 한 행성에 별이 많은 경우(10장, M5)와 같은 문제의 다른 크기다. 이 규칙이 행성별 한도보다 우선한다(10장).

재발견으로 들어온 별이 기간 밖일 때 (v0.6: SPEC 6장 S3, 지금 코드 기준으로 고침. PO 결정, PR #24)

- **기간을 "직접 지정 [그 별 날짜 ~ 오늘]"로 바꾼다.** 기간 탭이 직접 지정으로 바뀌고 날짜 2칸에 그 범위가 들어간다. 개수 · 행성 크기 · 별도 그 기간 기준으로 바뀐다.
- 그다음 그 별의 행성으로 자동 비행하고, 도착하면 그 별의 W-03이 열린다. 비행이 2.5초 안에 끝나지 않으면(탭이 가려져 화면이 갱신되지 않을 때 등) 기다리지 않고 W-03을 연다.
- 토스트는 띄우지 않는다. 바뀐 기간은 기간 탭에서 보인다.
- 별이 기간 안에 있으면 기간은 그대로다.
- 바뀐 기간의 별이 2,000개를 넘으면 별 상한 초과 상태가 되어 별은 그리지 않는다. W-03은 그대로 열린다.
- v0.4의 "기간은 그대로, 그 별 하나만 핑크로" 안은 데모 일정(11/12) 때문에 쓰지 않는다. 다시 넣으려면 데모 이후 새 이슈로 다룬다.

| 미리보기 | 종류별(아래 표) |
| 정보 | 종류, 넣은 날짜 "2026-11-11 · 0일 전" |
| 행동 | 원본 열기(텍스트는 없음), 폴더에서 보기 |
| 메모 | 3줄 입력, 입력을 멈추고 0.6초 뒤 저장. 아래에 "입력을 멈추면 저장돼요 → 저장 중… → 저장됨" |
| 행성 옮기기 | 선택 상자. 바꾸면 별이 새 행성으로 날아가고 목록으로 돌아가며 토스트 "'OO'(으)로 옮겼어요" |
| 지우기 | 글자 링크 "이 별 지우기" → 확인 창 |
| 발 | "이 별 탐사선에 싣기", 이미 실었으면 비활성 "탐사선에 실은 별이에요" |

| 종류 | 미리보기 |
|---|---|
| 이미지 | 4:3 상자에 이미지, 왼쪽 아래에 파일 이름 꼬리표 |
| 파일 | 확장자 아이콘(52×62, 노랑, 오른쪽 위 모서리 18px) + 파일 이름 + "확장자 · 크기" |
| 링크 | 링크 제목(굵게) + 주소(mono, `--mute`) |
| 텍스트 | 본문 그대로, 점선 테두리 상자 |

원본 파일은 편집하지 않는다. 이 화면에서 바뀌는 것은 메모와 행성뿐이다.

### W-04 탐사선

가운데 모달, 최대 640px × 80vh.

| 영역 | 요소 |
|---|---|
| 머리 | "탐사선" + 개수 배지, 형식 탭: Claude 프롬프트(기본) / MCP 리소스 |
| 실은 목록 | 별마다 칩(색 점 · 제목 · ✕), 끝에 노랑 칩 "+ 이 기간 우주 전체 싣기". 최대 높이 132px, 넘치면 스크롤 |
| 미리보기 | mono 13px, 흰 바탕, 스크롤 |
| 개인정보 띠 | 항상 보임 "복사한 내용만 밖으로 나가요. 붙여넣기 전에 확인해 주세요." |
| 발 | 왼쪽 "비우기", 오른쪽 "닫기" + "복사하기" |

- 복사되면 토스트 "복사했어요. Claude 대화창에 붙여넣으세요". 클립보드가 막히면 미리보기를 전부 선택하고 "선택했어요. Ctrl+C로 복사하세요".
- 비어 있으면 미리보기에 "아직 실은 별이 없어요…" 안내, 복사하기 · 비우기 비활성.
- 이미지 · 파일은 이름과 메모만 텍스트로 넣고 "이미지는 내 PC에만 있어요. 필요하면 Claude에 따로 첨부하세요"를 붙인다(SQ2 결정 전 임시안).
- MCP 리소스 탭은 축소 1순위다. 빠지면 탭 없이 Claude 프롬프트만 둔다.

## 8. 3D 규격

### 캐릭터 (2등신 우주인, 오리지널)
- 흰 헬멧 · 남색 바이저 · 하늘색 눈 2개(3.4초마다 깜빡), 노랑 벨트, 핑크 가슴판 · 안테나 공 · 부츠, 보라 제트팩 + 노랑 탱크 2개.
- 불꽃: 바깥 `#ff8a2a`, 안쪽 `#fff1a0`. 속도에 따라 길이 0.35 ~ 2배. 빠르면 뒤로 연기 방울(최대 40개 돌려 씀).
- 외곽선 배율 1.08.

### 행성
- 기본 반지름 3.6 ~ 6(행성마다 id로 정해 고정). 실제 반지름 = 기본 반지름 × (1 + 3.5% × 기간 안의 별 개수), 0.3초 동안 부드럽게 바뀐다. **별 50개에서 더 커지지 않는다(기본의 최대 2.75배, 가장 큰 행성 반지름 16.5).** 상한이 없으면 별 2,000개에서 71배가 되므로 M5(행성당 3D 별 최근 50개, 16장 미정)에 맞춘 **잠정값**이다(개발 C 제안, v0.6). M5가 정해지면 함께 바꾼다.
- 장식 4종(마을 · 수정 · 숲 · 바위)을 행성마다 하나. 북극에 핑크 깃발. 고리는 일부만.
- 자전 초당 0.06 rad. 외곽선 배율 1.035.
- 이름표: 흰 글자 + 잉크 외곽선, 둘째 줄은 "별 N개"(기간 안 별 개수, 구분 기호 포함). 행성 데이터에 설명 필드가 없어 부제 대신 개수를 쓴다(v0.6). 이름을 바꾸면 바로 다시 그린다.
- 행성 자리: 만든 순서대로, 행성 id로 정한 방향 · 높이(±8)로 원판 위(중심에서 20 ~ 50)에 놓는다. 먼저 놓인 행성과 가까우면(가장 큰 행성 둘이 겹치지 않을 거리 = 16.5 × 2 + 6) 바깥으로 4씩 민다. 같은 행성은 기간이 바뀌어도 같은 자리다. 행성 수 상한(50개, POLICY 2-4)까지 같은 규칙이다(v0.6. 시안의 "정해진 빈 자리 6곳"은 7번째부터 놓을 규칙이 없어 쓰지 않는다, 15장).

### 별
- 5각 별 압출, `--yellow`, 외곽선 배율 1.16. 고른 별(W-03이 열린 별) · 체크한 별은 핑크.
- 궤도 반지름 = 행성 반지름 + 2.4 ~ 4.2, 기울기 ±0.7 rad, 속도 0.18 ~ 0.38 rad/s.
- 기간 밖의 별은 숨기고 클릭되지 않는다.

### 배경 · 빛
- 바탕 `--space`, 먼 점별 약 1800개, 성운 4개(아주 흐리게), 멀리 툰 태양.
- 반구광 0.55 + 방향광 0.95 (시안의 three.js r128 기준). 제품에 들어간 three.js 0.187에서는 빛 단위가 바뀌어 **같은 밝기가 반구광 1.6 + 방향광 2.6**이다(개발 C 확인, v0.6). 음영 3단계 맵 `#5a5a5a / #b0b0b0 / #ffffff`.

## 9. 모션

### 9-1. 블랙홀 전환 (W-00 → W-01)

| 단계 | 시간 | 무엇이 일어나나 | 움직임 |
|---|---|---|---|
| 1. 열림 | 0 – 300ms | 블랙홀이 커지고 고리가 빨라진다 | scale 1 → 2.5, ease-in. 회전 속도 0.22 → 1.6 |
| 2. 흡입 | 180ms – 약 1000ms | 홈의 카드 · 글자가 버튼 쪽으로 빨려 들어간다. 가까운 것부터 | 요소마다 520ms, 30ms 간격, `cubic-bezier(.55,0,1,.45)`. 중심으로 이동 + scale 0 + 회전 ±30° + 투명. 배경 별 점은 통째로 140° 돌며 줄어든다(700ms) |
| 3. 닫힘 | 약 740 – 1040ms | 버튼 자리에서 잉크색 원이 퍼져 화면을 덮는다 | 원 반지름 0 → 화면 대각선, 300ms, 가속 |
| 4. 기다림 | 최소 380ms, 준비될 때까지 | 3D를 준비한다 | 가운데 무지개 고리가 돈다 |
| 5. 열림 | 650ms | 가운데 구멍으로 우주가 열린다 | 구멍 반지름 0 → 대각선, 감속. 카메라는 조망 거리의 80%에서 100%로 물러난다 |

- 건너뛰기: 1 ~ 3단계 중 클릭이나 Esc면 남은 흡입을 생략하고 닫힘을 120ms로 줄인다.
- 행성 · 별을 눌러 들어온 경우: 5단계가 끝나면 그 행성으로 자동 비행한다.
- 모션 줄이기 설정: 블랙홀과 흡입 없이 200ms 잉크 페이드 → 200ms 페이드 아웃.
- 재발견 알림으로 들어올 때: 전환 없이 W-01에서 시작한다.
- 만드는 법: 2D는 `transform` · `opacity` · `clip-path`만 움직인다. 열림 구멍은 잉크 막의 `radial-gradient`로 만든다. 왜곡 셰이더는 쓰지 않는다.

### 9-2. 돌아가기 (W-01 → W-00)
잉크 막의 구멍이 400ms 동안 닫히고, 홈이 250ms 페이드로 나타난다.

### 9-3. 그 밖의 움직임

| 움직임 | 정의 |
|---|---|
| 홈 블랙홀 평소 회전 | 아주 느리게(속도 0.22). 고리 3개가 서로 다른 속도 |
| 캐릭터 대기 | 위아래 0.14, 약 2.9초 주기 |
| 캐릭터 비행 | 진행 방향으로 최대 0.55 rad 숙임, 최대 속도 15 |
| 자동 비행 | 거리와 상관없이 1.2초. 천천히 출발해 빨라졌다가 천천히 멈춘다. 도착하고 0.2초 뒤 패널이 열린다 |
| 행성 충돌 | 표면 + 1.6에서 튕긴다 |
| 별이 옮겨감 | 위로 7 솟았다 궤도로 들어가는 곡선 1.5초, 가운데서 1.8배 |
| 패널 열림 | 0.92배에서 튀어 오름 0.22초 `cubic-bezier(.3,1.5,.6,1)` |
| 탐사선 싣기 | 탐사선 버튼 0.4초 동안 1.12배 |
| 새 항목 | 목록 항목 1.2초 핑크 |

모션 줄이기 설정이면 패널 튀어 오름, 항목 깜빡임을 끄고 블랙홀 회전을 아주 느리게 줄인다.

### 9-4. 조작

| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 이동(조망 → 비행) |
| Space · Shift | 상승 · 하강 |
| 드래그 · 휠 | 시점 회전 · 거리(5 ~ 80) |
| E / 행성 클릭 | 착륙(W-02) |
| 별 클릭 | 그 별로 날아가 W-03 |
| Esc | 확인 창(창이 스스로 닫음) → 탐사선(닫고 홈으로) → 전환 건너뛰기 → W-03에서 목록 → 패널 닫기 → 조망으로 순서. 마지막 단계는 패널이 닫혀 있을 때 조망으로 돌아간다(SPEC 2-5 `returnToOverview`) |

- 입력창 · 선택 상자에 포커스가 있거나 탐사선 · 확인 창이 열려 있으면 비행 키를 받지 않는다.
- 자동 비행 중 이동 키를 누르면 자동 비행을 멈춘다.
- 패널이 열려 있어도 비행 키는 받는다. 패널 행성에서 멀어지면(표면 + 14) 패널을 닫는다(SQ4, PO 결정).

- [ ] 조작 안내가 처음엔 크고, 이동 한 번 뒤 작아진다
- [ ] 기간 안의 별이 2,000개를 넘으면 별 없이 행성 이름 · 개수와 띠 배너가 보이고, "오늘만 보기"를 누르면 기간이 오늘로 바뀐다
- [ ] 기간 밖의 별로 재발견해 들어오면 기간이 직접 지정 [그 별 날짜 ~ 오늘]로 바뀌고, 그 행성으로 자동 비행한 뒤 그 별의 W-03이 열린다. 토스트는 없다
- [ ] 탭이 가려져 자동 비행이 끝나지 않아도 2.5초 안에 W-03이 열린다
- [ ] 별이 50개를 넘는 행성은 더 커지지 않는다
- [ ] 행성 이름표 둘째 줄이 "별 N개"다
- [ ] 기간을 바꿔도 같은 행성은 같은 자리이고, 행성끼리 겹치지 않는다

**W-02 · W-03**
- [ ] 체크한 별이 우주에서 핑크가 된다
- [ ] 별 0개 행성만 삭제가 활성이다
- [ ] 행성을 옮기면 별이 날아가 새 행성 궤도에 들어간다
- [ ] 메모가 입력을 멈추고 0.6초 뒤 저장되고 "저장됨"이 보인다
- [ ] Esc가 W-03 → 목록 → 닫기 → 조망 순서로 동작한다

**W-04**
- [ ] 개인정보 띠가 항상 보인다
- [ ] 비어 있으면 복사하기가 비활성이다
- [ ] 클립보드가 막혀도 선택 상태로 복사할 수 있다

**전환**
- [ ] 클릭 · Esc로 건너뛸 수 있다
- [ ] 모션 줄이기 설정에서 페이드로 바뀐다

## 13. 문구 규칙

- 쓰는 말: **별, 행성, 우주, 탐사선, 싣기, 복사하기**
- 쓰지 않는 말: 보내기, 전송, 발사
- 날짜와 "N일 전"은 모두 기록을 넣은 시각 기준
- 오류는 무엇이 안 됐는지 + 다음 행동을 한 줄로. 사과하지 않는다
- 버튼은 누르면 일어나는 일을 쓴다: "복사하기", "지우기", "탐사선에 싣기"
- 토스트는 끝난 일을 과거형으로: "실었어요", "옮겼어요", "지웠어요"
- 말투는 차분하고 단정한 해요체. 느낌표와 과장된 표현은 쓰지 않는다
- 숫자는 구분 기호를 넣어 정확히 쓴다: 1,240자, 2.4GB
- 값을 모르면 비워 두지 않고 "미확인"이라고 쓴다
