# SPACELOG 전체 화면 흐름 (챗봇 지식용)

기준: 2026-11-12 시안 (`design/` 폴더). 챗봇이 "이건 어디서 해요?", "이 기능이 있나요?"에 답할 수 있도록 화면, 이동 경로, 기능의 있고 없음을 한 문서로 정리했습니다.
화면 캡처는 `screenshots/` 폴더에 있습니다.

## 1. 서비스 한 줄 설명

SPACELOG는 흩어진 기록(이미지, 파일, 링크, 텍스트, CSV)을 **수집 앱**에 끌어다 놓으면 **웹 우주**에서 행성별로 모아 보고, 묶어서 관측하거나 AI에게 보낼 텍스트로 만들 수 있는 로컬 서비스입니다.

- **수집 앱**(PC 앱): 넣는 곳.
- **웹 우주**(브라우저): 보고, 정리하고, 묶는 곳. 웹에서도 기록을 넣을 수 있습니다.

## 2. 용어

| 용어 | 뜻 |
|---|---|
| 기록 | 넣은 것 하나(이미지·파일·링크·텍스트·CSV). 우주에서는 행성 둘레의 점으로 보입니다. 예전 이름은 "별" |
| 행성 | 기록을 모아 두는 분류. 색과 모양(기본·고리·성운)을 고를 수 있습니다 |
| 성운 | 행성 모양의 하나. 아직 구체화되지 않은 아이디어를 "조각"으로 가볍게 남기는 곳 |
| 별자리 | 기록 여러 개(또는 하나)에 **관측 목적**을 붙여 저장한 묶음. 여러 행성의 기록을 함께 묶을 수 있습니다 |
| 관측소 | 별자리와 재발견 기록을 보는 화면. CSV는 대시보드로, 사진·텍스트는 모아 봅니다 |
| 탐사선 | 기록을 실어 **하나의 텍스트로 묶어 복사**하는 화면 (AI에게 붙여 넣기용) |
| 재발견 혜성 | 예전에 넣은 기록을 다시 보여 주는 것. "N일 전 오늘의 기록" |
| 블랙홀 | 행성을 끌어다 넣어 보관(삭제)하는 곳. 다시 꺼낼 수 있습니다 |
| 기간 | 오늘 / 이번 주 / 이번 달 / 전체 / 직접 지정. 기록을 **넣은 날짜** 기준 |

## 4. 우주 홈(W-01) 화면 구성

| 위치 | 요소 | 누르면 |
|---|---|---|
| 위 왼쪽 | SPACELOG / **기록 N** / **행성 N** / **별자리 N** | 각 칩이 오른쪽 창에 해당 목록을 열고 닫음 (한 번에 하나) |

| 왼쪽 아래 | 확대 조절(+ / 배율 / −), **챗봇 버튼**(파란 원) | 확대·축소, 챗봇 새 탭으로 열기 |

| 왼쪽 아래 | **행성 간 거리 카드** (3D에서만) | 행성 줄 → 그 행성으로 이동 |
| 오른쪽 | 행성으로 바로 날아가기 / 별자리 바로 보기 / 기록 목록 | 이동, 별자리 열기·숨기기, 기록 체크 |
| 가운데 아래 | **기록 넣기** | 웹에서 파일·메모 넣기 |
| 오른쪽 아래 | **위치 편집 / 행성 추가 / 탐사선 · N / 관측소 · N** | 각 기능 |

## 5. 주요 흐름

### A. 넣기
1. 수집 앱에 파일·링크·텍스트를 끌어다 놓거나 붙여 넣습니다(Ctrl+V). 단축키 Ctrl+Shift+S는 클립보드를 바로 넣습니다. 간단한 메모도 넣을 수 있습니다.
2. 확인 화면(S-02)에서 행성을 바꾸거나 메모를 남깁니다. **취소**하면 방금 넣은 기록이 지워집니다. 몇 초 뒤 접히며, 다시 펼치면 그대로 있습니다.
3. "우주 보기"로 웹 우주를 엽니다.
- 웹에서도: 우주 홈의 "기록 넣기", 또는 빈 행성 패널에 파일을 끌어다 놓기 / "기록 추가하기".

### B. 둘러보기
1. 우주 홈에서 행성을 누르거나 "행성으로 바로 날아가기"에서 고릅니다. 키보드 E는 가까운 행성에 착륙합니다.
2. 행성 패널이 열립니다. 처음에는 **오늘 넣은 기록**이 보이고, 아래 버튼(오늘 / 이번 주 / 이번 달 / 전체)으로 넓힙니다.
3. 기록을 누르면 기록 상세. 위의 ‹ › 로 같은 행성의 이전·다음 기록을 넘깁니다.
4. Esc로 돌아갑니다.

### C. 별자리 만들기
- **행성 패널에서:** 기록을 체크 → "별자리 만들기 (N)" → 이름, 관측 목적, 보기 방식을 정하고 만들기.
- **우주 홈 기록 목록에서:** 여러 행성의 기록을 체크 → "별자리 만들기". 여러 행성에 걸친 별자리는 우주에 선으로 이어집니다.
- **관측소에서:** "선택한 기록"을 보다가 "별자리로 저장".
- 수정: 별자리 기록 창의 "별자리 수정하기"(이름, 관측 목적, 체크로 기록 넣고 빼기, 풀기) 또는 관측소의 "별자리 수정".
- 우주에서 선 숨기기: "별자리 바로 보기" 카드의 체크 상자.

### D. 관측소에서 보기
- 들어가는 길: 오른쪽 아래 "관측소 · N" / 별자리의 "관측소에서 보기" / 기록을 체크한 뒤 "바로 보기"(저장 전 묶음).
- **별자리 관측:** 보기 방식 4가지 — 시각화 대시보드, 표 · CSV, 사진 모아보기, 텍스트 모아보기. 대시보드는 CSV 파일의 열로 만듭니다(묶는 기준, 값, 평균/합계, 막대/도넛, 쓸 열). 내보내기: AI용 텍스트 복사, CSV 복사, CSV 내려받기.
- **재발견 혜성 관측:** 넣은 지 7일이 넘은 기록을 모아 봅니다. 정확히 7일 전 기록에 "오늘의 재발견" 표시.

### E. 탐사선으로 AI에게 보내기
1. 싣기: 기록 목록에서 체크 후 로켓 버튼 / 행성 패널에서 체크 후 "탐사선에 싣기" / 기록 상세의 "탐사선에 싣기".
2. 오른쪽 아래 "탐사선 · N"을 엽니다.
3. 형식(Claude 프롬프트 / MCP 리소스)을 고르고 "복사하기". 자동으로 보내지지 않으며, 복사한 텍스트를 AI에 붙여 넣습니다.

### F. 재발견
- 수집 앱이 하루 한 번 OS 알림을 띄웁니다. 누르면 웹에서 그 기록의 행성으로 이동한 뒤 기록 상세가 열립니다.
- 웹 우주 홈 왼쪽 아래의 재발견 혜성 카드로도 들어갑니다.
- 관측소 "재발견 혜성 관측"에서 지난 기록을 한꺼번에 봅니다.

### G. 행성 관리
- 추가: 오른쪽 아래 "행성 추가" 또는 행성 메뉴의 "새 행성 만들기".
- 수정: 행성 패널 → 행성 메뉴 → "행성 수정" (이름, 색 7가지, 모양 3가지). 이름만 바꾸려면 패널 위의 "이름".
- 합치기 / 빈 행성 삭제: 행성 메뉴.
- 위치 바꾸기: "위치 편집"을 켜고 행성을 끌기. 겹치는 자리에는 놓이지 않습니다.
- 삭제와 복구: 위치 편집 중 행성을 **블랙홀**로 끌어 넣기 → 확인 → 보관. 블랙홀을 누르면 보관한 행성을 꺼내거나 완전히 삭제할 수 있습니다. 마지막 남은 행성은 넣을 수 없습니다.

### H. 체험 가이드 (12단계)
맨 위 "체험 가이드" 스위치로 켜고 끕니다. 아래 바에 체험 끝내기 / 전 단계로 돌아가기 / 다음 행동 버튼이 있습니다.

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 수집 앱 | 예시 카드를 끌어다 놓기 |
| 2 | 수집 앱 | 저장 확인, 웹 우주로 이동 |
| 3 | 웹 | 행성에 착륙 |
| 4 | 웹 | 목록에서 기록 열기 |
| 5 | 웹 | Esc로 목록에 돌아가기 |
| 6 | 웹 | 기록을 체크하고 별자리 만들기 |
| 7 | 웹 | 별자리를 관측소에서 열기 |
| 8 | 웹 | 관측소 보기 방식 4가지 눌러 보기 |
| 9 | 웹 | 수집 앱으로 이동 |
| 10 | 수집 앱 | 재발견 알림 누르기 |
| 11 | 웹 | 재발견한 기록 상세 확인 |
| 12 | 웹 | 관측소의 재발견 혜성 관측으로 마무리 |

체험이 만든 별자리("cvs 활용 데이터 대시보드")는 체험이 끝나면 지워집니다. 체험에 탐사선 단계는 없습니다.

## 6. 기능 변동 요약 (팀 원안 대비)

### 추가된 것
- 2.5D 보기(기본)와 3D 보기 전환, 3D의 행성 간 거리 카드
- 별자리(관측 목적이 있는 기록 묶음), 우주 위 별자리 선과 보기/숨기기
- 관측소: 별자리 관측(대시보드·표·사진·텍스트), 재발견 혜성 관측
- CSV 내용 저장과 규칙 기반 대시보드, 번호 열 자동 제외
- 블랙홀(행성 보관·복구·완전 삭제), 위치 편집, 행성 겹침 방지
- 행성 수정(색·모양), 성운과 "조각" 단위
- 기간: 이번 달, 전체
- 우주 홈 기록 목록(전체 보기 / 행성별 보기, 체크), 상단 칩 토글
- 행성 패널의 기간 버튼, 기록 상세의 이전·다음 넘기기
- 웹에서 기록 넣기(파일, 메모), 빈 행성에 끌어다 놓기
- 텍스트 기록의 실제 내용 표시, 이미지 미리보기
- 수집 앱: 넣은 뒤 취소, 메모 넣기, 접혀도 유지, 다른 도구에서 가져오기 카드(연결 예정 표시)
- 웹에도 뜨는 재발견(혜성 카드), 확대 조절, 챗봇 버튼(외부 링크)
- 체험 가이드 12단계와 On/Off 스위치

### 바뀐 것
- 화면 문구 "별" → "기록"
- 시각 스타일 전체(검정 바탕, 단색 카드, Pretendard)
- 조작: 2.5D에서는 WASD·드래그가 화면 이동, Space/Shift가 축소·확대
- 행성 삭제: "빈 행성만"에서 블랙홀로 기록이 있어도 보관 가능하게 (행성 메뉴의 "빈 행성 삭제"도 남아 있음)
- 재발견 도착 화면: 그 기록의 행성으로 이동한 뒤 기록 상세

### 한때 빠졌다가 되살린 것
- **탐사선**: 관측소로 대체했다가 핵심 기능이라 되살렸습니다. 관측소와 따로 있습니다.

### 없앤 것 (요청으로 삭제)
- 행성 그룹 기능
- 3D 거리 카드의 "편집한 순" 깊이 기준 (항상 "기록 넣은 순")
- 우주 위 행성 간 거리 점선 (거리는 카드의 숫자로만)
- 행성 모양 "위성", "혜성"
- 2.5D 보기의 거리 카드
- 관측소 대시보드의 행성별·종류별·날짜별 차트 (CSV 열 기준으로 대체)
- 우주 홈의 큰 "둘러보기 조작" 안내 카드 (한 줄 안내만 남음)

### 아직 없는 것 (챗봇이 "안 돼요"라고 답해야 하는 것)
- 기록·별자리 검색
- 블랙홀 외의 기록 휴지통 (기록 삭제는 되돌릴 수 없음)
- 다른 도구(Google Drive, Notion, Slack 등) 실제 연결: 버튼만 있고 동작하지 않습니다
- AI에게 자동 전송: 탐사선과 관측소 모두 복사·내려받기까지만 합니다
- AI가 만드는 대시보드: 대시보드는 CSV 열을 규칙으로 읽어 그립니다
- 링크·PDF 모아 보기
- 모바일 앱 (웹은 좁은 화면에서도 열리지만 일부 기능이 숨습니다: 위치 편집, 거리 카드)
- 재발견 알림 시각·주기 바꾸기는 수집 앱 설정에만 있습니다
- 로그인, 공유, 여러 기기 동기화 (로컬 서비스)

## 7. "어디서 해요?" 빠른 답

| 하고 싶은 일 | 가는 길 |
|---|---|
| 기록 넣기 | 수집 앱에 끌어다 놓기 / 웹 우주 홈 "기록 넣기" |
| 방금 넣은 것 취소 | 수집 앱 확인 화면의 "취소" |
| 특정 행성 보기 | 행성 클릭 / 오른쪽 "행성으로 바로 날아가기" |
| 예전 기록 보기 | 상단 기간을 "이번 달"이나 "전체"로 / 행성 패널 아래 기간 버튼 |
| 기록을 다른 행성으로 | 기록 상세 → 다른 행성으로 옮기기 |
| 기록 삭제 | 기록 상세 → 삭제 |

## 8. 챗봇 구현 시 주의

- 챗봇은 우주 홈 왼쪽 아래의 파란 원 버튼에서 **새 탭**으로 열립니다. 서비스 안에 내장된 창이 아닙니다. 주소는 배포 후 설정값(`chatbotUrl`)으로 넣습니다.
- 챗봇이 사용자의 기록 내용에 접근하는 연결은 정의돼 있지 않습니다. 지금 범위는 **사용법 안내**입니다. 기록을 읽게 하려면 탐사선의 복사 텍스트를 사용자가 붙여 넣는 방식이 현재 유일한 경로입니다.
- 화면 문구는 해요체, 짧게. "별" 대신 "기록"을 씁니다. 이모지와 느낌표는 쓰지 않습니다.
- 이 문서의 화면 이름과 버튼 문구는 시안 기준입니다. 구현 중 바뀌면 이 문서도 같이 고쳐야 합니다.
