# SPACELOG design.md

SPACELOG(우주 아카이브) 수집 앱 S-01~S-04와 웹 W-01~W-04에 적용한 디자인 규칙입니다.
다른 화면이나 결과물에 그대로 적용할 수 있도록 실제 값을 적었습니다.

## 1. 방향

- 어두운 우주 톤. 바탕은 검정, 그 위에 반투명한 어두운 패널을 올립니다.
- UI는 거의 보이지 않게. 장식 없이 내용과 행성 이미지가 주인공입니다.
- 포인트 컬러는 한 번에 하나. 지금 보고 있는 행성의 색이 곧 포인트 컬러입니다.
- 그라디언트, 네온 글로우, 패턴, 이모지, 색 있는 테두리 강조는 쓰지 않습니다.
- 웹은 우주 홈(W-01)이 항상 바탕에 있고, 나머지 화면은 그 위 오른쪽 패널로 열립니다. 새 페이지로 넘어가지 않습니다.

## 2. 색

### 바탕과 면

| 용도 | 값 |
|---|---|
| 페이지 바탕 (우주) | `#000000` |
| 바탕화면 예시 (수집 앱 뒤) | `#1c1c1e` |
| 패널·창 (불투명) | `rgb(30,30,32)` |
| 패널 (우주 위, 반투명) | `rgba(30,30,32,0.9)` + 블러 |
| 떠 있는 카드 (우주 위) | `rgba(37,37,39,0.78)` + 블러 |
| 타일 면 | `#272729`, `#2a2a2c`, `#252527` |
| 패널 안 행·카드 | `rgba(255,255,255,0.05)` |
| 칩·아이콘 버튼 면 | `rgba(255,255,255,0.08)` |
| 선택된 탭·행 | `rgba(255,255,255,0.14)` |

### 선

| 용도 | 값 |
|---|---|
| 패널·창 테두리 | `1px solid rgba(255,255,255,0.12)` |
| 카드 테두리 | `1px solid rgba(255,255,255,0.08)` |
| 버튼·칩 테두리 | `1px solid rgba(255,255,255,0.16)` |
| 목록 구분선 | `1px solid rgba(255,255,255,0.06)` |
| 드롭 영역·메모 입력 (비어 있음) | `1.5px dashed rgba(255,255,255,0.24)` |

### 글자

| 용도 | 값 |
|---|---|
| 기본 | `#ffffff` |
| 보조 | `#cccccc` |
| 비활성·미확인 값 | `#7a7a7a` |
| 밝은 면 위 (알림, 토스트) | `#1d1d1f` |

### 포인트 컬러

행성마다 두 단계를 씁니다. `base`는 버튼 면(흰 글자가 읽히는 진한 색), `light`는 어두운 바탕 위의 글자·선·점·진행 막대입니다.

| 행성 | base | light |
|---|---|---|
| 제품 기획 | `#2f6fe0` | `#8fb4ff` |
| 읽은 것들 | `#c2561f` | `#ffb07a` |
| 생각 조각 | `#7a4fd6` | `#c4a8ff` |
| 디자인 레퍼런스 | `#b8327f` | `#ff8fcf` |
| 회의록 | `#1f7a55` | `#6fdcaa` |
| 새 행성 1 | `#9a6a00` | `#ffd36f` |
| 새 행성 2 | `#0d7490` | `#7fe3ff` |
| 행성이 정해지지 않은 화면 (기본) | `#0066cc` | `#2997ff` |

- 포커스·선택 링: 기본 `#0071e3`, 행성 화면에서는 그 행성의 `base`.
- 선택된 칩·행의 면: `light`를 16~18% 투명도로 (`color-mix(in srgb, light 16%, transparent)`).
- 패널 루트에 CSS 변수로 덮어씁니다:
  `--color-primary: base; --color-primary-focus: base; --color-primary-on-dark: light;`

## 3. 글자

- 서체: **Pretendard Variable** 하나만 씁니다.
  `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css`
- 굵기: 400(본문), 600(제목·강조)만. 500은 쓰지 않습니다.
- 한글 줄바꿈: `word-break: keep-all`, 긴 문단은 `text-wrap: pretty`.
- 버튼과 키 표시는 줄바꿈하지 않습니다 (`white-space: nowrap`).

| 역할 | 크기 / 줄높이 / 굵기 | 자간 |
|---|---|---|
| 대형 제목 | 56px / 1.07 / 600 (좁은 화면 40px) | -0.28px |
| 섹션 제목 | 40px / 1.10 / 600 | 0 |
| 패널 큰 제목 | 32px / 1.15 / 600 | 0 |
| 카드 제목 | 21px / 1.19 / 600 | 0.231px |
| 본문 강조 | 17px / 1.24 / 600 | -0.374px |
| 본문 | 17px / 1.47 / 400 | -0.374px |
| 캡션 강조 | 14px / 1.29 / 600 | -0.224px |
| 캡션·버튼 | 14px / 1.43 / 400 | -0.224px |
| 작은 글씨 | 12px / 1.0 / 400 | -0.12px |
| 가장 작은 글씨 | 10px / 1.3 / 400 | -0.08px |

- 영문 상표(SPACELOG)와 구분 라벨은 자간을 넓힙니다: `letter-spacing: 0.08em ~ 0.18em`.

## 4. 간격과 크기

- 간격 단위: 4, 8, 12, 17, 24, 32, 48, 80px.
- 패널·창 안쪽 여백: 16~20px. 카드 안쪽 여백: 12~14px (작은 창), 20~24px (웹 카드).
- 요소 사이: 같은 묶음 8~12px, 다른 묶음 16~24px.
- 웹 오른쪽 패널: 폭 440px (탐사선은 460px), 화면 가장자리에서 16px 띄움.
- 수집 앱 창: 폭 340px, 화면 오른쪽에서 16px 띄우고 세로 가운데.
- 수집 앱 접힌 탭: 36×128px, 화면 오른쪽 끝에 붙임.
- 누를 수 있는 요소의 최소 크기: 44px (작은 창 안 보조 버튼은 32px까지).
- 배치는 flex/grid와 `gap`으로 합니다.

## 5. 모서리

| 대상 | 값 |
|---|---|
| 패널, 창, 큰 카드 | 18px |
| 패널 안 행, 작은 카드, 입력 | 14px |
| 목록 안 항목, 썸네일 | 10~11px |
| 키 표시(kbd) | 6px |
| 버튼, 칩, 탭, 검색, 토스트 | 9999px (알약) |
| 아이콘 버튼, 행성, 점 | 50% |

## 6. 그림자, 블러, 움직임

- 그림자는 하나만: `rgba(0,0,0,0.22) 3px 5px 30px 0`. 떠 있는 창·알림·토스트에만 씁니다. 카드에는 쓰지 않습니다.
- 블러: `backdrop-filter: saturate(180%) blur(20px)`. 우주 위에 올라가는 패널과 카드에만.
- 누름: 모든 버튼·칩에 `transform: scale(0.95)`, `200ms cubic-bezier(0.25,0.1,0.25,1)`.
- 호버 스타일은 따로 두지 않습니다 (링크 밑줄만).
- 포커스: `2px solid` 포커스 색, 2px 띄움.
- 전환: 짧은 페이드와 색 변화만. 튀거나 미끄러지는 움직임은 쓰지 않습니다.
- 카메라 이동(행성 착륙): 약 800ms. 패널은 착륙 후 약 850ms에 엽니다.

## 7. 구성 요소

### 버튼
- 주 버튼: 알약, 면은 포인트 `base`, 글자 흰색, 높이 40~44px.
- 보조 버튼: 알약, 투명 면, `1px solid rgba(255,255,255,0.16)`, 글자 흰색.
- 글자 버튼: 면·테두리 없이 포인트 `light` 색 글자.
- 아이콘 버튼: 원형 32~44px, 면 `rgba(255,255,255,0.08)` 또는 테두리만.
- 비활성: 글자 `#7a7a7a`, 누름 효과 없음.

### 탭 (분할 알약)
- 바깥: 알약, 면 `rgba(255,255,255,0.06)`, 테두리 `rgba(255,255,255,0.08)`, 안쪽 여백 4px.
- 항목: 높이 36~40px. 선택되면 면 `rgba(255,255,255,0.14)`, 글자 흰색 600. 아니면 글자 `#cccccc` 400.

### 칩 (필터)
- 높이 32px, 알약. 기본은 투명 면 + `1px rgba(255,255,255,0.14)`, 글자 `#cccccc`.
- 선택: 포인트 16~18% 면 + `2px solid` 포인트, 글자 흰색.

### 행성
- 원형. 하나의 행성 이미지를 CSS `filter`(hue-rotate, saturate)로 색만 바꿔 씁니다.
- 선택된 행성: 포인트 색 2px 링.
- 크기 기준: 목록 20~24px, 카드 36~40px, 상세 120px.

### 목록 행
- 높이 약 44px, 행 사이 구분선 `rgba(255,255,255,0.05~0.06)`.
- 구성: 썸네일(또는 종류 아이콘) + 제목(600) + 보조 정보(작은 글씨, `#cccccc`) + 오른쪽 상태.
- 선택된 행: 포인트 16% 면.
- 비어 있는 값은 "미확인"으로 쓰고 `#7a7a7a`.

### 진행 막대
- 높이 3~6px, 알약. 바탕 `rgba(255,255,255,0.08~0.12)`, 채움은 포인트 `light`.

### 스위치
- 44×26px 알약, 손잡이 20px 흰 원.
- 켜짐: 면 포커스 색, 손잡이 왼쪽 21px. 꺼짐: 면 `rgba(255,255,255,0.18)`, 손잡이 왼쪽 3px.
- 옆에 "켜짐"/"꺼짐"을 작은 글씨로 함께 씁니다.

### 키 표시 (kbd)
- 작은 글씨, 여백 `3px 8px`, 모서리 6px, 면 `rgba(255,255,255,0.1)`, 글자 흰색.

### 입력
- 한 줄 입력: 높이 44px, 모서리 14px, 투명 면, 점선 테두리. 포커스 시 `1.5px solid` 포인트 `light`.
- 검색: 알약, 면 `rgba(255,255,255,0.08)`, 왼쪽에 돋보기 아이콘 14px.

### 드롭 영역
- 높이 148px, 모서리 14px, 점선 테두리.
- 드래그 중: `2px solid` 포인트 `light` + 포인트 16% 면.
- 안의 문구는 상태마다 한 덩어리 (아이콘 + 제목 + 한 줄 설명).

### 토스트
- 화면 아래 가운데. 흰 면, 글자 `#1d1d1f`, 알약, 여백 `12px 20px`, 그림자. 약 2.4초 뒤 사라짐.

### 운영체제 알림 (S-03)
- 폭 340px, 모서리 18px, 면 `rgba(245,245,247,0.92)`, 글자 `#1d1d1f`, 그림자.
- 구성: 검정 36px 앱 아이콘 + 앱 이름·시각(작은 글씨) + 제목(600) + 본문 한 줄(말줄임).

### 확인 단계
- 삭제·합치기는 같은 패널 안에서 한 번 더 확인받습니다. 브라우저 확인창은 쓰지 않습니다.

## 8. 아이콘

- Lucide 선 아이콘(2px 선, 둥근 끝)만 씁니다.
  `https://unpkg.com/lucide-static@0.469.0/icons/<이름>.svg`
- 크기 14~22px. 어두운 바탕에서는 흰색으로 뒤집고(`filter: invert(1)`) 투명도 0.7~0.85.
- 쓰는 아이콘: orbit(앱), rocket(탐사선), search, settings, chevron-left/right, chevrons-right(접기), download(드롭), sparkle(드래그 중), check, image, file-text, link, type, layers(여러 개), bell.
- 이모지와 직접 그린 그림은 쓰지 않습니다. 로고는 글자(SPACELOG)로만 씁니다.

## 9. 문구

- 말투: 차분하고 단정한 해요체. 짧게 씁니다. ("저장했어요", "놓으면 별이 됩니다")
- 제목은 마침표로 끝낼 수 있습니다. 느낌표와 과장된 표현은 쓰지 않습니다.
- 버튼: 1~3어절, 동작이 먼저. ("우주 보기", "탐사선에 싣기", "복사하기")
- 용어: 별(기록), 행성(카테고리), 탐사선, 싣기, 복사하기. "보내기", "전송", "발사"는 쓰지 않습니다.
- 날짜와 "N일 전"은 모두 기록을 넣은 시각 기준입니다.
- 오류: 무엇이 안 됐는지와 다음 행동을 한 줄로. 사과 문구는 붙이지 않습니다.
  예: "로컬 서버가 꺼져 있어요. 앱을 다시 켜 주세요."
- 빈 상태도 안내합니다. 예: "수집 앱에 끌어다 놓으면 첫 별이 생겨요."
- 숫자는 구분 기호를 넣어 정확히 씁니다. (1,240자, 2.4GB)

## 10. 키보드

- 화면정의서: W·A·S·D 이동, Space 상승, Shift 하강, 드래그 시점, E 착륙.
- 이 시안(2.5D): W·A·S·D와 드래그는 화면 이동, Space는 멀어지기, Shift는 가까워지기, E는 가까운 행성에 착륙.
- 행성이나 "행성으로 바로 날아가기" 목록을 누르면 클릭 한 번으로 착륙합니다.
- Esc는 한 단계씩 닫습니다: 별 상세 → 행성 패널 → 우주 홈.
- 입력창에 포커스가 있을 때는 비행 키를 받지 않습니다.
- 패널이 열려 있는 동안에도 비행 키를 받지 않습니다.

## 11. 하지 말 것

- 그라디언트 배경, 네온 글로우, 색 있는 왼쪽 테두리 강조
- 한 화면에 포인트 컬러 두 개 이상
- 카드 그림자, 여러 종류의 그림자
- 이모지, 느낌표
- 굵기 500, Pretendard 외 서체
- 브라우저 기본 확인창

## 12. 표현 규칙 (DESIGN-REVIEW D6)

수치는 `docs/DESIGN-REVIEW.md`(1차 초안, 2026-11-11) 1장 기준입니다. 별 상한 2,000개는 DEMO AC-우주-8의 잠정 수치입니다.

### 별
- 별 하나 = 기록 하나. 우주 홈에서는 행성 둘레 궤도 위의 점으로 그립니다 (지름 5px, 행성의 `light` 색).
- 궤도 점은 행성당 최대 12개. 정확한 수는 행성 이름 아래 "별 N"으로 항상 숫자로 씁니다.
- 선택한 기간에 들어온 별만 셉니다. 기준은 기록을 넣은 시각입니다.

### 행성
- 행성 크기는 그 기간의 별 수를 따릅니다: `64 + √(별 수) × 30` px.
- 가장 큰 행성이 27개를 넘으면 상대 크기로 바꿉니다: `64 + 156 × √(별 수 ÷ 가장 많은 별 수)` px. 가장 큰 행성이 220px를 넘지 않습니다.
- 별이 0개인 행성은 40px, 투명도 0.45로 남겨 둡니다. 숨기지 않습니다.
- 밝기는 이 한 가지만 뜻합니다: 흐린 행성 = 선택한 기간에 별이 없음. 별의 밝기는 쓰지 않습니다.
- 착륙한 행성과 E로 착륙할 수 있는 행성에는 행성 `light` 색 2px 링을 둡니다.

### 별 상한 폴백 (D3)
- 기간 안의 별이 2,000개를 넘으면 별(궤도 점)을 그리지 않고 행성과 개수만 보여 줍니다.
- 상단 칩을 "별 2,400 · 개수만 표시"로 바꾸고, 안내 문구를 한 줄 띄웁니다.
- 행성 이름과 "별 N"은 평소와 같은 자리에 같은 크기로 남습니다. 행성 패널 목록은 전체를 보여 줍니다.

### 데모 시드 (D2)
- 행성 4개, 이번 주 별 20개 (DEMO 1장 사전 준비).
- 7일 전 기록이 반드시 들어 있어 재발견이 동작합니다.

### 재발견 진입 (D7)
- 알림을 누르면 그 별이 있는 행성으로 이동한 뒤 그 별의 상세가 열립니다 (DESIGN-REVIEW 0-1절 PO 확정).
- 별이 어디 있는지는 행성의 링과 별 상세 맨 위 뒤로 가기의 행성 이름으로 알 수 있습니다.

## 참고
