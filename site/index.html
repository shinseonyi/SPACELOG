1

모은다

화면 가장자리의 작은 드롭존에 이미지·파일·링크·텍스트를 끌어다 놓습니다. 전역 단축키로 클립보드도 바로 저장됩니다.

다시 만난다

하루 한 번 “7일 전 오늘의 별” 알림이 옵니다. 누르면 그 별이 있는 행성으로 날아가 상세가 열립니다.

3

내보낸다

고른 기록을 Claude가 읽기 좋은 형식으로 만들어 미리 보고 복사합니다. 고른 것만 나갑니다.

소스로 실행하기

세 줄이면 됩니다

git clone https://github.com/delightPIP/teamproject.git
cd teamproject/apps/collector
npm install && npm start
수집 앱이 켜지면 로컬 서버도 같이 뜨고, 트레이 아이콘의 “우주 보기”를 누르면 기본 브라우저에서 내 우주가 열립니다. 서버는 127.0.0.1에만 열리고 실행할 때마다 새 토큰을 만들어서, 다른 웹페이지는 접근하지 못합니다. 우주 화면까지 보려면 저장소 안에서 web을 한 번 빌드해 두세요 (npm install && npm run build -w @spacelog/web).

실행이 막힌다면

Windows

  • SmartScreen 경고가 뜨면 추가 정보 → 실행.
  • 회사·학교 PC의 앱 제어 정책에 막히면 실행 자체가 안 됩니다. 이때는 소스로 실행하세요.
  • 기본 포트는 47800이고, 쓰고 있으면 자동으로 다음 번호를 찾습니다.

macOS

  • “확인되지 않은 개발자” 경고가 뜨면 macOS 14 이하는 앱을 우클릭 → 열기, macOS 15 이상은 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.
  • “손상되었기 때문에 열 수 없습니다”가 뜨거나 그래도 막히면 터미널에서 xattr -dr com.apple.quarantine SpaceLog.app 로 격리 속성을 지웁니다.
  • 알림을 받으려면 시스템 설정 → 알림에서 SpaceLog를 켜 주세요.

무엇이 밖으로 나가나요

나가는 것

  • 링크를 저장할 때, 그 사이트에서 제목과 썸네일을 한 번 가져옵니다.
  • 탐사선에서 사용자가 직접 복사한 내용. 복사 전에 미리보기로 확인합니다.

나가지 않는 것

  • 기록, 파일, 메모, 사용 기록. 전부 내 PC에만 남습니다.
  • 로그인, 계정, 클라우드 동기화, 텔레메트리 — 아예 없습니다.
  • 원본 파일은 건드리지 않고 보관함에 복사본을 둡니다.
